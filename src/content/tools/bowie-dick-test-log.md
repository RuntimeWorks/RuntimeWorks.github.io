## The daily air-removal test, in short.

What the CDC guidelines say about air-removal testing on pre-vacuum (dynamic air-removal) sterilizers, and what each entry records.

-   A pre-vacuum (dynamic air-removal) steam sterilizer is tested for air removal with a Bowie-Dick test every day it is used, in an empty chamber. <cite>(CDC/HICPAC, 2008 disinfection and sterilization guideline)</cite>
-   This log is filled in before the first load of the day, so a failed test is found before any pack is processed.
-   The 2003 dental guidelines ask for periodic air-removal testing as the sterilizer manufacturer recommends. <cite>(CDC, 2003 dental infection-control guidelines)</cite>
-   If a sterilizer fails the air-removal test, it is not used again until it has been inspected by sterilizer maintenance personnel and passes the test. <cite>(CDC, 2003 dental infection-control guidelines)</cite>
-   Each entry on this sheet records the date, the time, the test type, the lot number, the pass or fail result and the operator.

## Four steps, before the first load.

The sheet follows the same order as the test itself: run it, record it, sign it, act on a failure.

01

### Print, or type then print

Print the blank sheet, or fill the header and the rows on screen first. It is laid out for US Letter, portrait.

02

### Run the test before the first load

Run the air-removal test the sterilizer manufacturer specifies — a Bowie-Dick pack, a process challenge device (PCD) or another test.

03

### Record the row and sign it

Date, time, sterilizer, test type, lot number, then pass or fail and the operator's name or initials.

04

### If it fails, write the action

Note what was done in the last column. A sterilizer that fails the air-removal test is not used again until it has been inspected and passes the test.
