## What CDC says about part-time sterilizers

The weekly schedule is written per machine. Correct functioning of sterilization cycles should be verified for each sterilizer by the periodic use, at least weekly, of biological indicators (CDC, 2003 dental infection-control guidelines). "Each sterilizer" is the whole answer for a backup unit.

For a unit that runs only now and then, the source is explicit rather than silent: CDC does not provide a separate recommendation for sterilizers that are used on a part-time basis (CDC, Best Practices for Sterilization Monitoring in Dental Settings). There is no lower frequency here to quote, so this page does not offer one.

The test itself does not change with the machine's workload. Monitor sterilizers at least weekly by using a biological indicator with a matching control, meaning a biological indicator and a control from the same lot number (CDC, 2003 dental infection-control guidelines).

The weekly baseline in full — what sits on top of it for every implant load, and what happens after a failed test — is in [how often a dental office must spore test its sterilizer](/guides/how-often-to-spore-test/).

## Florida counts hours of use, not just days

Florida writes its own intervals. Adequacy of steam under pressure (e.g. autoclave) or chemical vapor sterilization must have their efficacy verified by appropriate biological monitoring at least once every 40 hours (2,400 minutes) of use or at least once every 30 days, whichever comes first (Florida rule 64B5-25.003).

Dry heat and ethylene oxide sterilizers run on a longer clock: their efficacy must be verified with appropriate biological monitoring every 120 hours of operation at sterilization parameters or every 30 days, whichever comes first (Florida rule 64B5-25.003).

Use time is determined by multiplying the number of cycles by the individual cycle time (Florida rule 64B5-25.003). For a backup unit the two clocks pull apart: a quiet month accrues little use time, yet the 30-day limit can still arrive first (Florida rule 64B5-25.003).

If you want the arithmetic for your own unit, [the Florida spore test due-date calculator](/tools/florida-spore-test-calculator/) shows the earliest of the 7-day, 2,400-minute and 30-day limits, with the formula and a worked example.

## Where the two schedules disagree

The weekly baseline and Florida's rule measure different things, so they can point to different dates. Both are shown as written.

The sources behind this page do not pick a winner when the two dates differ; the rule pack records the clash and leaves the choice to the product (US sterilizer rule pack, item K2). Dental Logbook will not pick one silently: it treats the earliest date as the due one — 7 days since the last test, 2,400 use-minutes for steam and chemical vapor (7,200 for dry heat and ethylene oxide), or 30 days — and it records which of the three set the date. Where Florida's phrase "individual cycle time" is undefined, the logbook counts the full logged cycle, start to end: that reading accrues fastest.

## Record which cycle type the test covered

The routine weekly test is worded per sterilizer (CDC, 2003 dental infection-control guidelines), and the rule pack records a scoping disagreement behind that wording: the weekly test runs per sterilizer, while qualification runs its test series separately for each cycle type (US sterilizer rule pack, item K6).

So a good log runs one weekly test per sterilizer and writes down which cycle type the test rode in. Dental Logbook will record the cycle type with every spore test, and run qualification and requalification series per cycle type, so a passing test shows what it covered.

## What to record

A good entry for a backup unit's test is short:

-   the date of the test, and the sterilizer it covered, since the weekly test is set for each sterilizer (CDC, 2003 dental infection-control guidelines);
-   the cycle type the indicator rode in;
-   the biological indicator and the control, from the same lot number (CDC, 2003 dental infection-control guidelines);
-   the result, negative or positive, with the date it was read;
-   in Florida, the use time the test covers, since use time is determined by multiplying the number of cycles by the individual cycle time (Florida rule 64B5-25.003).

Dental Logbook will keep these fields for every test, with the cycle type on the entry.

## What these sources do not say

The rows this page may quote are narrow, and where they are silent the page says so instead of filling the gap:

-   They set no separate schedule for backup or part-time units: CDC does not provide a separate recommendation for sterilizers that are used on a part-time basis (CDC, Best Practices for Sterilization Monitoring in Dental Settings).
-   They set no rule for testing a unit before its first load after a long idle spell. The rows quoted here do not cover bringing a stored sterilizer back into service, so this page does not invent one.
-   They set no lower frequency for a unit that never runs, and say nothing about removing an idle unit from the sterilization area.
-   They set no state interval other than Florida's. What your own state requires sits with the state board, and the state-by-state rows live in [the how-often guide](/guides/how-often-to-spore-test/).
