# html-validate settings and why

- `no-raw-characters` relaxed: an `&` between query parameters in a link (`?subject=…&body=…`) is not an ambiguous
  character reference under the HTML standard; the relaxed mode still fails on ambiguous ones.
- `doctype-style` off: the HTML standard accepts `<!doctype html>` in any case; Astro writes its redirect pages in lower
  case and its other pages in upper case.
- `long-title` off: 18 guide and tool titles run past 70 characters. They are kept exactly as the live site published
  them, so search results that already show them keep matching.
